# Robotic Process Automation in UiPath

This repository contains a UiPath automation project for order processing.

## Project Description

The goal of this project is to automate a business process related to orders using UiPath.  
The automation can read order data, process files, and support repetitive tasks in an efficient way.

## Technologies Used

- UiPath Studio
- Robotic Process Automation
- XAML workflows
- JSON configuration files

## Project Structure

- `Main.xaml` – Main workflow of the automation
- `Bestellung_Automation.xaml` – Order automation workflow
- `project.json` – UiPath project configuration
- `BestellungenFolder/` – Folder for order-related files
- `Orchestrator_Documentation/` – Documentation for UiPath Orchestrator

## How to Run

1. Open the project in UiPath Studio.
2. Open `project.json`.
3. Run `Main.xaml`.
4. Check the output and processed files.
